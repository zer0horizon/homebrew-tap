# Homebrew Tap

Homebrew formulae for [zer0horizon](https://github.com/zer0horizon) projects.

## Install

Add this tap to your system (you only need to do this once):

```bash
brew tap zer0horizon/tap
```

Then, you can install any tool available in this tap:

```bash
brew install ipd
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [`ipd`](https://github.com/zer0horizon/ip-discovery) | Discover your public IP address via DNS, STUN, or HTTP |

## Updating

```bash
brew update
brew upgrade ipd
```
